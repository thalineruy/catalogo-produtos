Configurações da empresa, categorias, usuários e estatísticas gerais.

Área restrita

Esta seção é exclusiva para usuários com nível Administrador. Fale com um administrador do sistema se precisar de acesso.

1. Configurações Gerais
Desativado

Demonstrativo: esta é uma simulação visual. Nenhuma integração real está ativa e nenhum dado sai deste sistema.

Como funciona

Em uma integração real, o sistema trocaria dados com o ERP da empresa por uma API autenticada por token (enviado no cabeçalho Authorization), sincronizando produtos, estoque e saídas automaticamente em intervalos regulares. A chamada teria este formato: 

POST /api/v1/erp/sync
Authorization: Bearer ••••••••4f21
Content-Type: application/json
